
# JD Decors - Modern Interior & Home Furnishing Website

A fully responsive, luxury interior design and home decor e-commerce front-end website developed as an **Aptech eProject**.

## ✨ Features
* **100% Fully Responsive Layout:** Seamlessly works on Mobile, Tablet, and Desktop screens.
* **Modern UI/UX:** Clean, elegant aesthetic with dark luxury tones and smooth typography.
* **Featured & Best Collections:** Organized product grids for interior art, decors, and furniture.
* **Interactive Navigation:** Smooth navigation bar with quick access to shop, about, and contact sections.

---

## 🛠️ Tech Stack
* **HTML5** - Structure & Markup
* **CSS3 / Bootstrap** - Styling & Responsive Grid System
* **JavaScript** - Client-side interactivity
